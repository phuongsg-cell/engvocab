Cấu hình Google Cloud API

Để ứng dụng kết nối trực tiếp với Google Drive cá nhân của bạn, hãy nhập **Client ID** được tạo từ Google Cloud Console.

Hướng dẫn tạo Client ID nhanh:

  1. Truy cập Google Cloud Console.
  2. Tạo dự án mới & Bật API **Google Drive API**.
  3. Tại trang Credentials -> Tạo OAuth 2.0 Client ID (Web Application).
  4. Thêm địa chỉ trang web của bạn vào **Authorized JavaScript origins**.
